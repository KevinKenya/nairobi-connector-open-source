# Lagos Vision (lagos-lite)

## Обзор
**Lagos Vision** — это высокопроизводительный движок визуализации и рендеринга для Nairobi OS. Он разработан для визуализации миллионов точек данных с субмиллисекундной задержкой путем прямого проецирования аналитических данных из файлов `memfd` в графический конвейер (GPU pipeline) без копирования. Lagos работает как headless-демон, транслирующий JPEG-кадры на виджеты Jupyter Notebook через WebSockets.

## Ключевые особенности
- **Рендеринг с нулевым копированием (Zero-Copy)**: Данные проецируются напрямую из дескрипторов `memfd` в буферы `wgpu`.
- **Аппаратное ускорение**: Использует библиотеки `egui` и `wgpu` (Vulkan, Metal, DX12 или OpenGL) для отрисовки графиков сверхвысокой плотности.
- **Даунсемплинг LTTB**: Выполняет алгоритм LTTB (Largest-Triangle-Three-Buckets) на стороне графического процессора для сохранения визуальной точности при отображении гигантских наборов данных.
- **Событийно-ориентированная архитектура**: Не потребляет процессорное время в режиме ожидания; рендеринг запускается только при обновлении данных или взаимодействии с пользователем.

## Архитектура
Lagos Vision состоит из следующих компонентов:
- **Lagos Lite**: Основная библиотека, обеспечивающая конвейер рендеринга.
- **Lagos Vision Daemon**: Бинарный процесс, управляющий поверхностью `wgpu` и сервером WebSocket.
- **Lagos Widget**: Компонент Python `anywidget`, отображающий видеопоток в интерактивном режиме.

## Установка и настройка

### Требования
- **GPU**: Графический процессор с поддержкой Vulkan (или OSMesa для программной эмуляции в отсутствие физического дисплея).
- **Системные зависимости**: `libosmesa6-dev`, `mesa-utils`, `xvfb`.

### Сборка
```bash
cargo build --release -p lagos-lite --bin lagos-vision-daemon
```

## Использование

### В составе Nairobi OS
Интерфейс Lagos обычно вызывается автоматически при использовании метода Python `SovereignFrame.plot()`.

### Отладка в ручном режиме
Вы можете запустить демон вручную для проверки конвейера рендеринга:
```bash
./target/release/lagos-vision-daemon --fd <FD_INT> --width 1000 --height 400
```

## Разработка

### Реализация пользовательского слоя визуализации
1.  **Модификация конвейера**: В файле `src/pipeline.rs` определите ваши вершинные и фрагментные шейдеры (WGSL).
2.  **Обновление структуры буфера**: Сопоставьте входящие данные `memfd` с группами связывания вашего нового шейдера.
3.  **Интеграция с интерфейсом**: Добавьте элементы управления (ползунки, кнопки) в интерфейс `egui` в файле `src/device.rs`.

### Работа в Headless-окружениях
В бездисплейных облачных средах, таких как Google Colab, Lagos использует `xvfb-run` или OSMesa:
```bash
xvfb-run -s "-screen 0 1024x768x24" ./target/release/lagos-vision-daemon ...
```

## Тестирование
Lagos включает визуальные интеграционные тесты, которые захватывают отрисованные кадры и сравнивают их с эталонными изображениями.
```bash
cargo test -p lagos-lite
```

## Устранение неполадок
- **Сбой WebSocket-соединения**: В облачных средах (Colab/SageMaker) убедитесь, что прокси-порт проброшен корректно. Nairobi Python обрабатывает это автоматически при обнаружении окружения Google Colab.
- **Адаптер WGPU не найден**: Убедитесь, что драйверы GPU установлены. При работе в системах без графического ускорителя Lagos автоматически попытается переключиться на программный рендеринг (software adapter).
